# BetaHorizon

Rust reimplementation of a Beta 1.7.3 game client and supporting server/common crates.

## Run the client

Install the Rust stable toolchain, then run `run-client.bat` on Windows or `./run-client.sh` on Linux/macOS. The workspace defaults to render-debug mode; set `OLDMINE_RENDER_DEBUG=0` to disable it.

The source tree contains the Rust workspace and its PNG assets. Original Java sources, Minecraft JAR files, local runtime data, and build output are excluded from version control.
